## 2. Gotchas learned this session (important)
- **`shape.translate()` / a shape's own location is DROPPED** when the object also gets a `_place`
  Placement. To offset an `add_shape_obj` shape, pass `x/y/z` (and for `_R`, flip the mirrored axis'
  sign), OR bake into geometry with `transformShape(matrix, True)`. `obj.Shape.BoundBox` reflects the
  object Placement, so a silently-ignored translate looks like "no-op".
- **Fusing a fill box leaves a phantom-rectangle seam** in the render (coplanar faces not auto-merged);
  call `shape.removeSplitter()` to merge them. Filling a hole with a slightly-oversized box makes it
  worse (internal faces); match the exact hole walls.
- **Sub-component visibility via the GUI races the GUI init** — hiding can silently no-op and save
  everything visible (this is why `view_assembly.sh VI` first showed the frame). Fixed by DELETING
  non-selected objects instead. Any future "show only X" must not depend on `ViewObject.Visibility`
  right after `showMainWindow`.
- **Classifier drives grouping:** `_classify_subcomponent(name)` → I/II/II_R/III/IV/V/VI, catch-all "I".
  New object names must contain the right token (e.g. `Top_Stepper`/`Bolt_TSH_`→V, `Router_Clamp`/
  `Bolt_RC_`/`Bolt_RailZ_`/`Rail_Z`/`Engine_Holder_P2`/`Bolt_P2_`→VI).
- Some imported STEPs ship a **duplicate coincident solid** (p2of2 had 2); dedupe with `Solids[0]`.
- Coords: X=depth(front 0→back 900), Y=width(left 0→right 793, centre 396.5), Z=vertical. Shapes are
  LOCAL; `add_shape_obj`/`add_step` add z=93 ⇒ world Z = local + 93.
